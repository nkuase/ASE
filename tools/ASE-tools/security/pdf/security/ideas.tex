\begin{frame}[fragile]{Information Security}

\begin{itemize}
	\item We are living in an information age. Any information is digitized, stored, and shared. 
	\item Digitized information is easy to leak, hack or modify. 
	\item So, there are many tools and rules for secure information. 
	\item As software engineers, we should understand information security to make the software products that secure information that they process. 
\end{itemize}

\end{frame}

\begin{frame}[fragile]{CIA Triad}

\begin{itemize}
    \item We have a principle in information security called the CIA Triad. 
	\item The CIA triad stands for \underbar{C}onfidentiality, \underbar{I}ntegrity, and \underbar{A}vailability.
	\item As software engineers, we should strive for a good balance among the elements that constitute the CIA principle. 
\end{itemize}

\begin{frame}[fragile]{}
\begin{columns}%
\begin{column}{0.7\textwidth}%
\begin{itemize}
  \item Confidentiality makes sure that only authorized personnel are given access or permission to modify data
  \item Integrity helps maintain the trustworthiness of data by having it in the correct state and immune to any improper modifications
  \item Availability means that the authorized users should be able to access data whenever required
\end{itemize}
\end{column}%

	\item It tries to enhance availability by allowing the authorized persons can access the features that the software provides.
