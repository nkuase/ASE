\begin{frame}[fragile]{The Problems of Symmetric Encryption}

\begin{itemize}
	\item We should share keys to use symmetric encryption. 
	\item What if we should share keys with millions of people? 
	\item We can easily guess that it is likely that hackers can get the key that many people share. 
\end{itemize}

\end{frame}

\begin{frame}[fragile]{The Solution}

\begin{itemize}
	\item Then, how about the idea of sharing not the key, but the lock? 
	\item If we can make the locks available to everybody, anyone who wants to share secret information can use the lock to encrypt it before they send me the information. 
	\item As I do not share the keys, I am the only person who can decrypt the secret information (unlock the lock). 
\end{itemize}

\begin{frame}[fragile]{}

\begin{itemize}
	\item This algorithm, called the RSA algorithm, is a revolutionary idea that changed the encryption/decryption system.
	\item In RSA, we call the lock a public-key and the key private-key. 
	\item The acronym "RSA" comes from the surnames of Ron Rivest, Adi Shamir, and Leonard Adleman, who publicly described the algorithm in 1977. They got the Turing award in 2002.
	\item This RSA algorithm (or public key algorithm) is used practically widely when sharing information on the Internet. 
\end{itemize}

\end{frame}

\begin{frame}[fragile]{Q \& A}

\begin{itemize}
	\item Q: When I used GitHub, I had to generate some keys using the program ssh-keygen and upload it on GitHub. Is it the public key that I uploaded?
	\item A: Yes. You uploaded the public key (lock) on GitHub so that when GitHub needs to send you information, it uses the public key (lock) to secure the information. As you only have the matching private key (key), you alone can decrypt the information. 
\end{itemize}

\end{frame}

\begin{frame}[fragile]{keypair.js Module}

\begin{itemize}
	\item We need to generate a public and private key pair in the keypair.js module. 
\end{itemize}

\begin{Code}{}%
\begin{lstlisting}[firstnumber=1, label=glabels, xleftmargin=0pt, basicstyle=\tiny]% 

export {privateKey, publicKey}
const { generateKeyPairSync } = require('crypto');

const { privateKey, publicKey } = generateKeyPairSync('rsa', {
  modulusLength: 2048, // the length of your key in bits
  publicKeyEncoding: {
    type: 'spki', // recommended to be 'spki' by the Node.js docs
    format: 'pem',
  },
  privateKeyEncoding: {
    type: 'pkcs8', // recommended to be 'pkcs8' by the Node.js docs
    format: 'pem',
  },
});
\end{lstlisting}%   
\end{Code}%

\end{frame}

\begin{frame}[fragile]{Encryption}

\begin{itemize}
	\item Then, using the public and private key, we can encrypt any information. 
\end{itemize}

\begin{Code}{}%
\begin{lstlisting}[firstnumber=1, label=glabels, xleftmargin=0pt, basicstyle=\scriptsize]% 

const {  publicEncrypt, privateDecrypt } = require('crypto');
const { publicKey, privateKey } = require('./keypair');

const secretMessage = 'ASE 285 students are superb!'
const encryptedData = publicEncrypt(
    publicKey,
    Buffer.from(secretMessage)
  );
console.log(encryptedData.toString('hex'))
\end{lstlisting}%   
\end{Code}%

\end{frame}

\begin{frame}[fragile]{Decryption}

\begin{itemize}
	\item We can decrypt the information using the private key. 
\end{itemize}

\begin{Code}{}%
\begin{lstlisting}[firstnumber=1, label=glabels, xleftmargin=0pt, basicstyle=\scriptsize]% 

const { publicEncrypt, privateDecrypt } = require('crypto');
const { publicKey, privateKey } = require('./keypair');

const decryptedData = privateDecrypt(
    privateKey,
    encryptedData
);

console.log(decryptedData.toString('utf-8'));
\end{lstlisting}%   
\end{Code}%
