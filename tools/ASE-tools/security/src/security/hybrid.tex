\begin{frame}[fragile]{}
\begin{itemize}
	\item The calculations for symmetric-key algorithms are fast, but exchanging keys is an issue.
	\item The calculations involved in public-key cryptography take a lot of time, but exchanging keys to implement a public key scheme is simple.
	\item How can we solve this problem?
	\item Hybrid Encryption.
\end{itemize}
\end{frame}

\begin{frame}[fragile]{}

\begin{itemize}
	\item We encrypt and share the shared key (symmetric-key) using the public-key before we start communication.
	\item Once we share the shared key, we can communicate securely using the shared key. 
\end{itemize}
