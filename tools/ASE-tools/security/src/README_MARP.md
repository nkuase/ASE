## Quick Start

### VS Code (Recommended)
1. Install "Marp for VS Code" extension
2. Open `SE_security.md`
3. Press `Ctrl+K V` to preview
4. Export: Right-click → "Marp: Export slide deck..."

### Marp CLI
```bash

npm install -g @marp-team/marp-cli

# Preview
marp -p SE_security.md

# Export
marp SE_security.md --pdf
marp SE_security.md --pptx
marp SE_security.md --html
```
